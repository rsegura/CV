Data Lake & Streaming

Real-time Profile Enrichment

Built and operated streaming enrichment over terabyte-scale Apache Iceberg tables, coordinating dozens of real-time consumers to keep audience profile attributes and social relationships up to date.

Machine Learning & NLP

Interest Classification with Applied ML

Built a production interest classification pipeline spanning LoRA fine-tuning, reranking, and model serving on Kubernetes with vLLM. Integrated inference with a real-time enrichment consumer, reaching more profiles and improving the correctness of assigned interests across 444 categories.

Architecture & approach +

Fine-tuned an embedding model with LoRA to retrieve candidate interests, then applied a cross-encoder to rerank them. Used agreement between the models to address confident but incorrect predictions. Deployed the inference service on Kubernetes with vLLM and connected it to a streaming consumer that enriches profiles with inferred interests.

Also used Qwen models served through vLLM for near-real-time enrichment, integrating language model inference into the data processing architecture.

Evaluation showed F1 improving from 0.255 to 0.390 after fine-tuning, and strict precision increasing from 36% to 52% with model agreement. These measure distinct improvements in the classification pipeline.

Sentence Transformers LoRA / PEFT Kubernetes vLLM Qwen Cross-Encoders Contrastive learning Information Retrieval

Query Engine & Performance

VEGA: Shared Access to Audience Data

Designed an asynchronous query platform over the data lake, unifying Athena and Trino behind an API with queue-based decoupling, execution traceability, and retries. Gave product teams shared access to data without having to manage each query engine directly.

Architecture & approach +

Decoupled query submission from execution through queues, allowing clients to submit long-running jobs and retrieve results asynchronously. Implemented execution traceability, retries, and Redis-based rate limiting to track queries, recover from failures, and control demand. Added a data catalog, query examples, and a query builder to support adoption.

Worked with product teams to integrate the platform into their workflows. Adoption reduced costs and the number of systems they needed, and enabled new data-driven product verticals previously constrained by scale.

Voice & AI Agents

Voice Agent Architecture Prototype

Pet project built to understand voice agents through hands-on experimentation. Uses a simulated clinical pre-screening interview as a concrete scenario for exploring real-time conversation orchestration.

Architecture & approach +

Integrated a streaming STT → LLM → TTS pipeline: Deepgram converts speech to text, a language model orchestrated through OpenRouter handles the dialogue, and ElevenLabs generates spoken responses, connected through LiveKit/WebRTC. The agent conducts structured interviews and assesses answers against predefined inclusion and exclusion criteria.

Implemented explicit conversation state transitions and SQLite WAL persistence for crash recovery, backed by automated tests. The focus is learning how voice, model orchestration, and durable state fit together in an experimental prototype.

LiveKit Deepgram ElevenLabs OpenRouter SQLite WAL
